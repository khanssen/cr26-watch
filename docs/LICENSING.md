# Licensing and publication boundary (resolve before first public push)

- CR26 JSON snapshots: US Government work, public domain (17 USC §105). Redistributable; keep the source URL and version in each filename.
- Scripts: Apache-2.0 (patent grant, corporate-friendly) or MIT. Either suits tooling meant to be adopted.
- `docs/` analysis: CC-BY-4.0 so it can be quoted with attribution; the marker discipline is the attribution hook.
